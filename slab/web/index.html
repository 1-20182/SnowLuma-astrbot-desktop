      接入 QQ（登录机器人账号）
      SnowLuma 不会弹二维码：扫码是在 QQ 客户端里扫
      
        
        
          
      1. 用机器人账号登录 QQ 客户端：打开电脑版 QQ（NT 版），用要当机器人的号扫码登录；登录后别退出、别切号，让 QQ 留在后台运行。
        2. 
          
      2. 启动 SnowLuma：在上面卡片点「启动」。它会自动发现并注入 QQ 进程，日志会出现 [Hook] login detected → [OneBot] session started。
        3. 
          
      3. 确认接入：点「检查账号」，能列出 QQ 号就成功了；也可以打开 SnowLuma 面板看进程与连接状态。
        4. 
          
      4. 保持在线：关掉 QQ 客户端 = 机器人掉线；多开就多登一个 QQ，SnowLuma 会为每个账号各建一条连接。
        5.

          没检测到账号？常见原因（点开）
          
        
            
      • 权限不一致：QQ 用管理员运行，SnowLuma 也要管理员（反之亦然）；两者必须是同一个 Windows 用户。
        • 
            
      • QQ 版本太老：需要 QQ NT 版（9.9 及以上），老版不支持注入。
        • 
            
      • 杀软拦截：把 SnowLuma 安装目录加入白名单，再重启 SnowLuma。
        • 
            
      • 手动注入：SnowLuma 面板 → 进程列表 → 对目标进程点「注入 / 加载」；还不行就重启 QQ 再试。
        • 
            
      • 账号风控：新号或异地登录容易触发验证，先在 QQ 里完成验证再启动。
        • 
            
      • 完整说明见 docs/MANUAL.md「三、登录机器人 QQ」。

      帮助 · 五分钟上手
      
    
  
      
  
      
    
        
      
      1. 部署：在「部署」页点 下载安装（SnowLuma，建议 full 版）和 克隆并安装依赖（AstrBot）。
        2. 
      
      2. 登录 QQ：用**机器人小号**在电脑版 QQ（NT 版 9.9+）里扫码登录，登录后保持 QQ 在后台运行。
        
          SnowLuma 不会弹二维码——它通过注入 QQ 进程来接管会话，所以扫码动作在 QQ 客户端里完成。
        3. 
      
      3. 配置：填 QQ 号（建议小号）、大模型 API Key 与模型名，点「保存设置」。
        4. 
      
      4. 写入联动：「联调」页点「写入联动配置」，把端口与 Token 同步进两个项目。
        5. 
      
      5. 启动：「运行」页依序启动 AstrBot → SnowLuma；日志出现 [Hook] login detected 与 [OneBot] session started 即接入成功。
        6. 
      
      6. 验证：「运行」页点「检查账号」确认 QQ 号；然后在 QQ 里私聊机器人或群里 @它。
        7. 
    
      
    
      常见问题速查
      
    
        
      
      • 面板打不开：先确认「运行」页对应服务是绿灯，再看端口是否被占用。
        • 
      
      • QQ 未接入：先在 QQ 客户端扫码登录（SnowLuma 不弹二维码），再点「运行 → 检查账号」；仍不行见 docs/MANUAL.md 第三节。
        • 
      
      • 消息不回复：检查 API Key、模型名，以及触发规则是否匹配（群里需要 @ 或前缀）。
        • 
      
      • 多开 QQ：SnowLuma 会给每个已登录账号各建一条 AstrBot 连接，只要有一条正常就算连通。
        • 
      
      • 端口被占用：在「配置」页换一个端口，然后重新「写入联动配置」。
        • 
      
      • 杀软拦截 node.exe：把安装目录加入白名单后重试部署。
        • 
    
      
    
      完整手册：docs/MANUAL.md（含「登录机器人 QQ」图文步骤）；其它：README.md、docs/DEPLOY.md、docs/TROUBLESHOOTING.md、docs/ARCHITECTURE.md。接口调试可访问 /api/docs。
